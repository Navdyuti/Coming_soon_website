# Navdyuti Labs

Worlds are not built. They are born.

This repository contains the official **coming soon website** for **Navdyuti Labs**, a next generation game studio focused on building immersive digital worlds inspired by sacred mathematics, mythology, and cosmic storytelling.

* Cinematic intro animation
* Canvas based sacred geometry visuals
* Spatial 3D audio experience
* Cosmic particle background
* Waitlist system
* Community links

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API
* WebAudio API
